# Evently

Evently is a responsive event landing page for a free one-day gathering in Bhubaneswar.

## Features
- Responsive event landing page with animated interactions
- Live countdown to 12 December 2026
- Schedule filtering by track
- Reviews section and newsletter signup
- Free ticket claim flow with demo payment form
- Light and dark themes with accessible contrast
- Mobile navigation and reduced-motion-friendly animations

## Getting started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

- `pnpm dev` — start the development server
- `pnpm build` — create a production build
- `pnpm start` — serve the production build

## Stack

Next.js, React, TypeScript, Tailwind CSS, and Lucide icons.
